# غداء البيت

تطبيق ويب لتنظيم غداء البيت: منيو يومي تلقائي، ونواقص من الطباخ للسائق، وتسجيل أسعار المشتريات وتقارير شهرية. الواجهة بخمس لغات: العربية والهندية والبنغالية والفلبينية والإنجليزية.

- الرابط: https://ghada-albait.github.io
- البيانات: Firebase (Firestore + Anonymous Auth)
- قواعد الحماية: `firestore.rules` (تُلصق في Firebase → Firestore → Rules)
- صور الأطباق المرجعية من Wikimedia Commons، مع اسم المصوّر والترخيص تحت كل صورة.
